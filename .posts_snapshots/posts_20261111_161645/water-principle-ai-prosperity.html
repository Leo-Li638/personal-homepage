上善若水：为什么「利他不生息」的人，在 AI 时代反而赚得最多？

老子说「水善利万物而不争」，多数人只引半句。本文还原《道德经》第八章全文与王弼、苏辙注解：七个「善」全是能力不是品德（居善地/心善渊/与善仁/事善能/动善时），「不争」的完整语境是「不争位置」而非「不做事」。2026 年的数据说这是最强商业模式：独立开发者把开源做成获客渠道（32K stars、600 万下载、MRR 14.5 万美元、公司仍是一人），而「被 AI 批量生产的东西都在贬值，必须靠人、时间和真实交付积累的都在升值」。附一张「2026 年什么在贬值/什么在升值」对照表与三个可执行动作，以及三点冷水：利他必须接住一个数字、不争的前提是先有东西可让、水在自然界免费但你的时间不是。

一、先把原文读准：老子到底说了什么

很多人引用"上善若水"只引半句，那是断章取义。

《道德经》第八章全文（《老子道德经》）：

上善若水。水善利万物而不争，处众人之所恶，故几于道。 居善地，心善渊，与善仁，言善信，正善治，事善能，动善时。 夫唯不争，故无尤。

注意这里有几个常被忽略的点：

① "不争"的完整语境是"不争"+"不处众人之所善"——是不要去抢位置，不是不要做事。

王弼注：「人恶卑也」——水处的地方是众人所厌恶的低处（低洼、潮湿、人不去的地方）。

② 老子紧接着列了七个"善"，每一个都是能力，不是品德。

原文含义王弼/苏辙注解
居善地择位置避高趋下，未尝有所逆
心善渊心境深静空虚静默，深不可测
与善仁待人真诚无私利泽万物，施而不求报
言善信言行一致圆必旋，方必折——随形就势
正善治治理精简洗涤群秽，平准高下
事善能发挥所长遇物赋形，而不留于己
动善时把握时机冬凝春伴，涸溢不失节

③ 最后一句"夫唯不争，故无尤"——"尤"是怨咎、过失。

所以老子的意思是：因为不跟人争，所以不会招来怨咎。这不是自我牺牲，这是风险控制。

苏辙的注解最狠：「水惟不争，故兼七善而无尤。」——水因为不争，同时具备了这七样"善"，而且没有一样会带来过失。

这句话放到 2026 年，我认为是整个系列里最值钱的一句。

二、2026 年的数据：水善利万物，是最强的商业模式

现在说 AI 时代。

案例一：那个把自己变成"默认选项"的人

独立开发者 Nevo 的完整动作序列，值得逐句拆：

  1. 2026 年初，开源个人 AI Agent 项目 OpenClaw 火了，几周涨到 10 万颗星，成为历史上增长最快的开源项目之一
  2. 几百万人在配置这个 Agent，冒出一个非常具体的问题：它要怎么往社交平台发内容？
  3. 这类工具的老牌是 Buffer 和 Hootsuite——仪表盘都做给人看，按人头收费，源码也封闭。Agent 要自己往平台发内容，它们没有一个接得上。
  4. Postiz 碰巧是开放的，接口还能被程序直接调用，成了少数 Agent 能用的那一个。
  5. Nevo 抓住了这一点。他没有写蹭热度的观点文，而是直接动手：把 Postiz 重新定位成"给 AI Agent 用的终极调度工具"，发布 postiz-agent 命令行工具和 MCP 服务端，让 Agent 能自己排期、自己发内容，还在 Agent 技能目录 ClawHub 里发布了 Postiz 技能包，给每一个 Agent 配每一个平台的组合做了程序化的落地页
  6. 后来一篇爆火的 OpenClaw 文章顺带提到 Postiz 是 Agent 往社交发内容的方式。流量和注册一下子涌进来，而且没停。

看这个序列的精妙之处：

步骤他做了什么对应"水"的哪个特性
把开源做成获客渠道宽松 License 白送，仓库 32K stars、约 600 万次下载利万物——免费铺漏斗
给每一个 Agent×平台组合做落地页别人做组合，他做基建事善能——遇物赋形
不写观点文，直接动手抢的是"接得上"这个位置居善地——去 Agent 真正缺的地方
等爆款文章顺带提一句不争流量，等流量自己来不争

他的 MRR：2.1 万 → 8 万 → 11.8 万 → 14.5 万美元（每天还多 1000 美元，年化快摸到 200 万美元）。公司还是他一个人，bootstrapped。

这个案例精确地演示了"水"的经济学：

  • 他没有靠打广告赚钱
  • 他没有靠写爆款文章赚钱
  • 他做的是让所有 Agent 都能用上他的东西

MRR 是结果，不是起点。

案例二：那个"不生息"的开源项目

再看另一组数字（AI Review Rating 汇总的一人公司成本结构）：

现金项你付什么代替
软件许可$0
搭建工时每工具的接入时间
托管服务器或实例
运维你自己就是 on-call
升级$0
故障全归你

注意最后三行。 开源在这张表里的位置是：软件许可 $0，但运维和故障全归你。

这就是"不生息"的准确含义：

  • 软件许可 = $0（你把利益让出去了）
  • 故障责任 = 全归你（你把成本留下来了）

老子说"居善地"——处众人之所恶。水往低处流，那低处是什么？

是没人愿意待的地方：低洼、潮湿、脏、累、赚不到快钱。

而"开源但不生息"的真实形态就是：把「使用」免费送出去，把「维护」留给自己。

这个交换在 2026 年第一次真正成立，因为它终于有了闭环：

AI 把分发成本打到接近零 → 免费送出去的东西能触达更多人 → 触达的人里有愿意付费的 → 付费的人帮你做传播 → 更多人免费用。

免费不是终点，免费是漏斗的顶端。

案例三：那个"不争流量"的定价法

还有一个细节值得单独说。

做 Agent 服务的公开分享里，「卖结果不卖工具」 是反复出现的一条：

给客户讲清楚「你这个 SKU 的竞品分析报告，点一下自动出」，而不是讲「这是一个基于什么架构的智能体」。

以及那句最关键的话：

「案例复制是最值钱的一步——第一个客户成交后，把过程整理成案例：痛点、方案、效果、回本周期，然后带着案例去敲下一个同类客户。因为同类客户痛点几乎一致，说服成本被案例直接打掉一半。」

"用案例说服"而不是"用广告说服"，这就是"处众人之所恶"——不去争流量的位置，去争"下一个客户已经被说服了"的位置。

定价上也是同一个逻辑：

  • 线下课 + Agent 智能体打包：6800 元，卖出上万份
  • 垂直行业 Agent：几百到三千元（客户决策快、复购空间大）
  • 企业知识库问答 / AI 客服 / 自动化工作流：单笔可达数万元

三、"不争"到底在争什么：2026 年什么在贬值

这才是本文真正想说的部分。

老子说"夫唯不争，故无尤"。那么在 2026 年，"争"什么最不划算？

我按"被争的东西"和"AI 能不能帮你争"两个维度，列一张表：

你在争什么AI 能不能帮你争2026 年性价比为什么
标题党 / 流量平台✅ 极强🔴 最低AI 批量生产同类内容 → 供给爆炸 → 注意力归零
技术炫技 / 参数规模✅ 极强🔴 极低通用算法岗 -30%~-50%、竞争比 100:1
"我会用 AI"✅ 极强🔴 极低已是标配；有 HR 说简历上写"熟练掌握 Java、SpringBoot"连面试都不安排
初级前端 / 基础 CRUD✅ 极强🔴 极低需求 -65%；初级后端薪资 18–25K → 8–12K
搜索排名 / SEO✅ 强🟡 低有人 SEO 砸 1.2 万美元，数据不行立刻停
"我能交付一个结果"🟡 中🟢 高需要行业 Know-how + 案例，AI 帮不上
"我有一群人愿意听我说"❌ 弱🟢 最高社会资本，AI 无法生成
"我知道这件事在我们这行是错的"❌ 弱🟢 最高领域判断，AI 幻觉区

这张表就是"上善若水"在 2026 年的全部含义：

凡是你能靠 AI 大量生产的东西，都在贬值。 凡是你必须靠人、靠时间、靠真实交付才能积累的东西，都在升值。

再具体一点：

AI 让"会做"变成了基础设施，让"做对"变成了稀缺品。

而"做对"这件事，恰恰是水的活：

老子的"善"AI 时代对应
与善仁（施而不求报）先免费给出能用的东西（开源、免费额度、公开方法论）
居善地（避高趋下）去 AI 够不着的地方（传统行业、垂直场景、线下交付）
事善能（遇物赋形而不留于己）为别人的产品做适配，而不是只做自己的
动善时（冬凝春伴）在需求爆发的那一刻已经在那儿了（Nevo 等 OpenClaw 爆火的那一刻）
心善渊（深不可测）不追热点，积累不可被复制的深度

而"不争"的对象，是流量、排名、标题、技术深度——这些全是 AI 能帮你批量生产的战场。

你把战场让给 AI，把阵地留给时间和人。

四、我要泼一盆冷水：三点它真的不成立

不写这一段，这篇文章就是鸡汤。

第一，"利他"不是商业模式，它是一种分发策略

残酷的实话：如果你的"利他"没有换来可观测的转化，那它不是策略，是自我感动。

判据很简单：

你的利他行为，必须能被一个数字接住。

你的利他行为该接住它的数字
开源一个项目stars / 下载 / 依赖它的项目数
免费给出方案留资数、试用数、转化率
写深度文章被引用次数、被 AI 引擎引用的次数（这正是 GEO）
帮别人解决问题转介绍数

如果一个数字都接不住，你做的不是"利他"，是"自我表达"。 这不丢人，但它不会变成收入。

第二，"不争"的前提是你已经强到不需要争

老子说"上善若水"，前面有半句：「是以圣人后其身而身先，外其身而身存。**非以其无私邪？故能成其私。」

翻译：正因为圣人把自己放在后面，反而成了最前面的；因为他不自私，反而成就了自己。

这有个前提：他已经有"道"了。

对还没建立起任何优势的人，"不争"不是策略，是放弃竞争。 你不争排名，别人会占那个位置；你不发声，别人会占你的位置。

所以正确的顺序是：先"处众人之所恶"（去没人去的地方建立优势），再"不争"（不去抢已经有人抢的位子）。

是先有东西可让，才谈得上让。

第三，"水"在自然界是免费的，但你的时间不是免费的

这是开源生意最容易被忽略的成本。

开源工具成本表里最狠的一行是：故障 → 全归你。

"施而不求报"在自然界没问题，因为水不需要维护。但在软件里，你的每一个 issue、每一次依赖更新、每一个 breaking change，都是你在付钱。

Nevo 的案例里有一半是这件事的反面教材：

  • SEO 砸了 1.2 万美元，数据不行立刻停 ← 这才是"不争"的正确用法
  • Gitroom 六个月见不到市场也停 ← 同上

他砍掉的都是"争流量的战场"，砍得很果断。而 Postiz 那些 Agent 适配，是"处众人之所恶"——去做 Agent 生态里没人愿意做的脏活。

这两个动作不冲突：一边坚决不争，一边死磕该争的地方。

如果只学前半句不学后半句，你会变成一个"开源了但没人用"的人。

五、具体怎么用：三个可以这周就做的动作

动作一：把你的"利他"接到一个数字上

今天就做这一件事：

  • 你写过技术文章 → 去你的站点和 llms.txt 里埋好，看 AI 引擎引用你几次
  • 你有 GitHub 项目 → 看 issue 区有没有人讨论（issue 区讨论 = 有人在替你传道）
  • 你帮同学解决过问题 → 记下来，这就是你的第一个案例

Nevo 的 Postiz 之所以能起来，是因为它有 32K stars 和 600 万下载做漏斗。 你的漏斗可能是 10 个人，但必须有。

动作二：找你的"低洼处"——AI 够不着的地方

老子的水不往高处流。往高处流的是"流量"。

AI 够得着的地方（别去）： 写一篇通用技术教程、做一个小工具、追一个热点。

AI 够不着的地方（去）：

  • 你那个行业的重复性工作（教育行业的学情分析、招商行业的客户跟进、制造业的质检报告……）
  • 需要现场、需要信任、需要交付承诺的活
  • 需要"这个做法在我们这行是错的"这种判断的活

我的答案还是教育。 我做学情推题模块时知道一件事：这个行业不信"AI 给的答案"，信"AI 给的可以向老师解释的判断依据"。 这个 Know-how 不是通用技术，是行业 Know-how。

动作三：做"有回报的不争"

具体做法：把 Nevo 的动作序列抄一遍，换成你的场景。

步骤Nevo 做的你可以做的
1. 找一个正在爆发的东西OpenClaw 爆火你所在领域的某个新工具/新政策/新平台
2. 找到"接不上"的地方Agent 发不了社交内容你的行业里某个重复流程没人能用 AI 打通
3. 不写观点文，直接动手做 CLI/MCP/技能包做一个能真跑的东西，哪怕很窄
4. 给每个组合做程序化落地页Agent×平台你的方案×你的行业细分
5. 等爆款顺带提你一篇 OpenClaw 爆文提到 Postiz这一步你无法加速，只能等——但你可以让自己"可被提到"

第 5 步最关键，也最反直觉：你不能争流量，但你可以让自己成为"那个被提到的东西"。

怎么做？让你的东西有"第三方可引用的价值"：

  • 开源（有 star 有人 issue）
  • 有公开可查的数据/榜单
  • 能被 AI 引擎检索并引用 ← 这就是我做 GEO 的原因

"被提到"是"不争"的最高形态：你没有争，你只是存在得足够清楚。

六、常见问题

Q：这是不是又在讲"佛系"？ 恰恰相反。 老子说的是"处众人之所恶"——主动去最难、最不体面、竞争最少的地方。这是很费力的选择，只是不浪费在没用的地方。

Q：开源自媒体现在还有机会吗？ AI 内容产能已经过剩了（闲鱼 AI 服务订单 +157%、AI 编程建站 +1732%），所以"也写一篇技术文"没机会。但"开源一个别人能用的东西"仍有——因为能被 Agent 调用的基建需求刚起来（Nevo 的 MCP 服务端、ClawHub 技能包就是这个位置）。

Q：不开源怎么做"利他"？ 先免费给出一个"完整可用的小结果"，而不是免费给"教程"。 教程会被 AI 抄走，能直接用的方案抄不走（因为它带着你的场景）。

Q：怎么判断我的"不争"是真策略还是逃避？ 两个测试：

  1. 数字测试：你的利他行为接住了哪个数？接不住 = 逃避。
  2. 交换测试：如果把你"让出去"的部分收回，你的价值还剩多少？如果全部价值都在"让出去"的那部分上，说明你的护城河就是廉价本身 —— 危险。

Q：那"上善若水"和"狡兔三窟"是一回事吗？ 是同一件事的两面。 三窟是结构（我要有几个藏身处），上善若水是姿态（我用什么方式扩张）。冯谖的三窟之所以能成，是因为冯谖"市义"——他先给了，才有了人心这一窟。 顺序不能反。

  • 《老子道德经》第八章：「上善若水。水善利万物而不争，处众人之所恶，故几于道。居善地，心善渊，与善仁，言善信，正善治，事善能，动善时。夫唯不争，故无尤。」
  • 《道德经》第七章：「是以圣人后其身而身先，外其身而身存。非以其无私邪？故能成其私。」
  • 王弼《道德经注》：「人恶卑也」「言人皆应於治道也」
  • 苏辙《老子解》：「水惟不争，故兼七善而无尤」；逐句注解——「避高趋下，未尝有所逆，善地也；空虚静默，深不可测，善渊也；利泽万物，施而不求报，善仁也；圆必旋，方必折，塞必止，次爻流，善信也；洗涤群秽，平准高下，善治也；遇物赋形，而不留于一，善能也；冬凝春伴，涸溢不失节，善时也」
  • 学习强国《〈老子〉第八章》（2020-12-28）：帛书甲本作「有静」、乙本与汉简本作「有争」，「有争」为误；王夫之注「以不争争，以无私私」
  • 《荀子·宥坐》孔子观于东流之水：「大遍与诸生而无为也，似德……似道……若有决行之，其应佚若声响，其赴百仞之谷不惧，似勇」

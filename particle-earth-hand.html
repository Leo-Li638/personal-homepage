深空制图仪 · 手势地球（第一号）

Vue 3 + Vite + TypeScript + Three.js + MediaPipe HandLandmarker。摄像头识别 21 个手部关键点，用手在空中「捏合 / 平移 / 握拳 / 张开」操控一颗点阵地球，并可在「制图」与「流星雨」两种视觉之间切换；左侧是深空制图仪表盘，底部是城市题注。

背景与目标

目标不是「做一个地球模型」，而是把地球变成可以用手直接操控的东西。为此需要同时解决三件事：手部关键点如何稳定地从摄像头流里取出来、如何把这些关键点翻译成镜头语言（缩放 / 环绕 / 模式切换）、以及点阵地球本身如何既有「制图」的克制质感，又能在流星雨模式下换一副面孔。

21 个关键点MediaPipe HandLandmarker 输出的手部骨骼点
2 种模式制图（chart）与流星雨（meteor）
50 座城市内置城市数据与重点城市题注
12 个渲染层可逐层隐藏，便于排查

关键做法

  • 相机轨道代替地球自转。参考视频里被选中的城市永远正对镜头，所以不做地球自转，而是让相机绕原点做球面轨道运动：camAz 取城市经度、camEl 取纬度，城市方向即视线方向。
  • 点阵地球是自定义 ShaderMaterial 的 Points。顶点按经纬度规则排布（不是 Fibonacci），贴图采样 earth-water.png 得到水陆掩码：陆地是亮白点 #dfeeff，海洋是暗蓝点 #143a5c，夜面城市灯由 earth-night.jpg 亮部转成暖金色点。
  • 所有「屏幕构图元素」都挂在相机上。太阳、点阵月球、倾斜轨道环、大范围辉光、流星都是 camera 的子对象（需要 scene.add(camera) 才能渲染），因此相机旋转时构图恒定；只有星野是世界坐标的 Points，用来在轨道运动时产生视差。
  • 光照方向在相机空间固定。从右上打光（SUN_LIGHT_CAM = (0.52, 0.46, 0.72)），每帧用 applyQuaternion(camera.quaternion) 转到世界空间，避免背面打光导致可见面变暗。
  • 流星雨模式用线性空间手写着色。自定义 ShaderMaterial 的输出会被 OutputPass 再做一次 ACES + sRGB 编码，因此颜色必须直接写线性值，不能塞 THREE.Color；法线 / 视线 / 光源全部换到 view 空间计算 fresnel，否则 fresnel 恒接近 1，整球惨白过曝。
  • 后处理链路。RenderPass → UnrealBloomPass → OutputPass；bloom 的 strength / threshold 随模式插值（meteor 阈值更高），避免大亮盘整体泛光糊成一片。
  • HUD 遥测每帧合并推送。场景把 Telemetry（模式、城市、经纬度、距率、帧率、手势、城市数、卫星数、信号、本地日期）通过 emit 推给 App.vue，再以竖排 12 行渲染；数字用等宽字体 + font-variant-numeric: tabular-nums 防止跳动。

交互方式

摄像头隔空手势：

  • 捏合开合（拇指–食指距离）→ 推远 / 拉近地球（距率 1.41×–3.10×）
  • 手掌平移 → 相机绕地球轨道旋转（经度 / 纬度跟随手掌）
  • 握拳并保持 → 切换到「流星雨」模式
  • 五指张开并保持 → 回到「制图」模式

同时保留键盘 / 鼠标通道：M 或空格切换模式、← / → 切换重点城市、H 显隐 HUD、F 全屏、拖拽旋转视角、滚轮缩放。停止操作 2.6 秒后进入自动巡览（制图模式下约每 9.5 秒切换一座城市，未检测到手时 5.2 秒）。

可验证入口

仓库 README 提供了完整的调试参数，便于复现与排查：

  • ?preview=1 —— 跳过摄像头授权，直接进入场景（截图 / 演示用）
  • ?mode=chart / ?mode=meteor —— 指定初始模式
  • ?city=上海 / ?city=San Francisco —— 指定初始焦点城市（中英文均可）
  • ?demo=0 —— 关闭自动巡览
  • ?hide=clouds,atmos,dots,ring,halo,glossy,stars,sun,moon,cities,meteors,bloom —— 逐层隐藏渲染层

仓库含两种模式的实拍截图（1600×1000），可与本地运行结果直接对照。

已知限制

  • MediaPipe 在部分核显机器上只能回落 CPU 推理，帧率约 24–30fps；场景本身在 60fps 以上。
  • 手势阈值（捏合 / 伸展）按当前环境调过，换光照或摄像头可能需要微调 useHandTracking.ts 中的 SMOOTH_* 与 ParticleEarth.vue 里的 spread > 0.72 / < 0.34。
  • 城市标签做了屏幕空间过滤（避开左侧面板与底部题注），城市极密集时仍可能相邻重叠。
  • 摄像头需要安全上下文：127.0.0.1 / localhost 可直接授权；用局域网 IP 打开需要 HTTPS。
